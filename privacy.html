개인정보처리방침

toegeun-uploader · 작성일: 2026년 11월 20일

1. 적용 범위와 운영자

이 방침은 YouTube 채널 「퇴근한 직업들」 운영자가 개인 PC에서 사용하는 toegeun-uploader와 이 안내 사이트에 적용됩니다. 일반 방문자에게 계정 가입이나 Google 계정 연결을 제공하는 서비스가 아닙니다. 앱은 YouTube API Services를 사용합니다.

2. 접근하거나 보관하는 정보

  • Google OAuth 액세스 토큰, 갱신 토큰, 만료 시각, 승인 범위
  • 연결된 YouTube 채널의 ID와 이름
  • 업로드한 영상의 ID·주소, 예약 시각, 업로드 이력과 오류 기록
  • 운영자 채널 영상의 조회수·좋아요·시청 시간 등 통계
  • 운영자가 준비한 대본, 이미지, 음성, 자막, 영상, 제목·설명 등 로컬 제작 자료

앱은 Google 계정 비밀번호를 수집하거나 저장하지 않습니다. 권한별 용도: youtube.upload는 영상 업로드, youtube.readonly는 채널 확인과 영상 상태 조회, youtube.force-ssl은 업로드한 영상의 썸네일·현지화 정보 수정, yt-analytics.readonly는 운영자 채널의 통계 확인에만 사용합니다.

3. 이용 목적과 외부 전송

Google 계정 연결 유지, 업로드 대상 채널 확인, 운영자가 지정한 영상 전송과 예약, 처리 결과 확인과 오류 진단, 채널 성과 확인을 위해 정보를 사용합니다. 토큰 교환·갱신 시 인증 정보가 Google로 전송되고, 업로드 시 영상 파일과 제목·설명·태그·공개 범위·썸네일이 YouTube로 전송됩니다.

Google·YouTube에서 받은 인증 토큰과 채널 데이터는 다른 사람에게 판매하거나 광고에 사용하지 않으며, 운영자 본인의 채널 운영 외의 목적으로 사용하지 않습니다. Google 및 YouTube의 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

4. 보관과 보호

OAuth 토큰과 연결 정보는 운영자 PC의 로컬 파일에만 저장되며 외부 서버로 보내지 않습니다. 제작 자료, 업로드 이력, 통계 자료도 운영자 PC의 로컬 프로젝트 파일로 보관합니다. 이 파일들은 PC 계정과 파일 접근 권한으로 보호되며, 운영자가 필요한 기간을 판단해 직접 관리하고 삭제합니다.

5. 권한 철회와 삭제

  1. Google 계정의 연결된 앱 관리에서 이 앱의 접근 권한을 언제든 철회할 수 있습니다.
  2. 로컬에 저장된 토큰 파일과 업로드 이력, 통계 자료는 운영자가 직접 삭제할 수 있습니다. Google에서 권한을 철회해도 로컬 파일이 자동으로 삭제되지는 않습니다.

이미 YouTube에 업로드된 영상은 로컬 파일 삭제나 권한 철회로 삭제되지 않으며, YouTube Studio에서 직접 관리할 수 있습니다.

6. 안내 사이트와 호스팅

이 안내 사이트에는 방문자 분석, 광고, 입력 폼, 추적 스크립트나 쿠키를 넣지 않습니다. GitHub Pages가 호스팅하므로 호스팅 제공자가 접속 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.
